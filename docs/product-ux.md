# Parcel Globe：使用逻辑、页面和功能 v1

> 2026-10-07。视觉见 `visual-direction.md`（Night Mail v2）。范围和 API 见 `PLAN.md`。

## 0. 设计原则
1. **地球是主界面，其余都是浮层。** 只有一个页面，不做多页跳转。
2. **一眼看懂**（借 Flighty）：不点开也知道每件包裹在哪、还要几天。
3. **贴进来就能用**：输入单号是唯一必做的操作，承运商、名字、刷新都自动处理。
4. **数据只在你自己手里**：包裹存在浏览器 IndexedDB，服务器只做转发、不存数据。

## 1. 核心使用循环
```
粘贴单号 → 自动识别承运商 → 查询轨迹 → 地理编码 → 地球上出现弧线
      ↑                                              ↓
  收到新快递 ← 签收（放烟花、弧线转青绿、慢慢淡出） ← 打开页面时自动刷新
```

## 2. 第一次使用（Onboarding，3 步，可跳过）
| 步 | 界面 | 说明 |
|---|---|---|
| 0 | 口令页 | 输入 `APP_PASSCODE` → 设置 HMAC cookie（30 天） |
| 1 | 「你住在哪？」 | 输入 ZIP 或城市；或点「用当前位置」（只取近似坐标，只存本地）。地球飞过去，家开始发光 |
| 2 | 「贴一个单号」 | 大输入框，下面放示例格式。可选「先看演示数据」，用内置的脱敏 fixtures 演示 |
| 3 | 承运商状态 | 显示 UPS / FedEx / USPS 各自是否配好 key（✓ / ✗ / 实验性），点 ✗ 跳到 README 对应段落 |

服务器没配任何 key 时，自动进入**演示模式**，顶部挂一条横幅。

## 3. 页面 / 视图结构（单页 + 浮层）
```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：Logo · 「3 件在途 · 1 件派送中」 · ＋添加 · ⟳ · ⚙   │
├───────────────┬──────────────────────────────────────────┤
│ 侧栏 Manifest  │                                          │
│ ─ 派送中       │            3D 地球（主画布）              │
│ ─ 在途         │                                          │
│ ─ 异常         │      选中包裹 → 底部弹出详情抽屉           │
│ ─ 最近签收     │                                          │
│ （归档折叠）    │                                          │
└───────────────┴──────────────────────────────────────────┘
```
| 视图 | 打开方式 | 内容 |
|---|---|---|
| **地球（首页）** | 默认 | 所有活跃包裹的弧线，加 30 天内签收、正在淡出的弧线 |
| **Manifest 侧栏** | 常驻（手机端是底部抽屉） | 机场大屏式列表：承运商 · `…4821` · `SZX→CMI` · 状态 · 「2 天」。按状态分组 |
| **包裹详情抽屉** | 点列表行或点弧线 | 名称/备注（可改）、进度条、预计送达、完整事件时间线（城市 · 时间 · 原文）、「在承运商官网打开」、复制单号、手动补点、归档/删除 |
| **添加单号** | ＋ 或直接在页面任意位置粘贴 | 支持单条或批量（每行一个，可写成 `单号 备注`），实时显示识别出的承运商，可以手动改 |
| **年度回顾** | 顶栏菜单 / 12 月自动出提示 | 5–6 页故事卡 → 最后一页是海报，导出 PNG |
| **归档** | 侧栏底部 | 所有已签收的包裹，可搜索、按年份或承运商筛选；可以把历史弧线「全部点亮」 |
| **设置** | ⚙ | 家的位置；刷新策略；淡出天数（默认 30）；减少动效；导入/导出 JSON；清空数据；承运商状态；退出登录 |

URL 用 hash 路由（`#/p/<id>`、`#/year/2026`），这样能直接给某个包裹或年度页加书签。

## 4. 地球上的交互
- **悬停弧线**：弹出小标签（备注 · 状态 · 「2 天」），同时其他弧线变暗。
- **点击**：镜头沿地平线飞到这条路线，打开详情抽屉。
- **空白处单击 / Esc**：回到总览，镜头缓慢自转。
- **中转站光点**：悬停显示「Louisville · 今年经过 7 次」。
- **双击家**：把所有在途包裹框进同一个画面。
- 美国国内的路线在地球上很短，镜头会自动拉近；2D 地图模式放到 v0.2。

## 5. 状态模型（UI 层面）
| 状态 | 列表标签 | 弧线 | 来源 |
|---|---|---|---|
| 待查询 | 灰 `PENDING` | 不画，只在发货城市显示一个点 | 刚添加，或承运商还没揽收 |
| 在途 | 琥珀 `IN TRANSIT` | 彗星光点 | 统一事件里的 `in_transit` |
| 派送中 | 亮琥珀 `OUT FOR DELIVERY` | 整条弧线亮起来，家的光环跳得更快 | `out_for_delivery` |
| 已签收 | 青绿 `DELIVERED` | 放烟花 → 转青绿 → 30 天内淡出 | `delivered` |
| 异常 | 红 `EXCEPTION` | 弧线停在最后位置，变红并闪烁 | `exception` / `return_to_sender` |
| 过期 / 查不到 | 暗灰 `UNKNOWN` | 不画 | 承运商返回找不到；14 天没有新事件 |

## 6. 刷新逻辑
- 打开页面或切回这个标签页时：刷新所有没签收、而且距上次刷新超过 15 分钟的包裹（逐个请求，失败了按指数退避重试）。
- 手动 ⟳：忽略 15 分钟限制，但每件包裹至少间隔 60 秒，防止撞上承运商的限流。
- 已签收的不再查询；异常状态的继续查，最多查 30 天。
- 页面开着的时候每 30 分钟轮询一次；切到后台就暂停。
- 没有服务器推送（serverless 架构）；同步版另作考虑。

## 7. 边界情况
- **承运商识别不出来**：让用户自己选；UPS 和 FedEx 都查一遍，取能返回结果的那家。
- **USPS 403**：详情页提示「USPS 限制收件人查询」，给出两个办法：手动输入发货城市，或粘贴 usps.com 上的轨迹文字，在本地解析。
- **城市解析失败**：这个事件仍然显示在时间线里，但不进入弧线；详情页可以手动选城市。
- **多件包裹（同一订单拆成几单）**：v0.2 支持把它们归成一组，弧线合并显示。
- **重复单号**：提示「已在列表中」，然后跳到那一件。
- **离线**：显示缓存的数据，顶部提示「离线，上次更新 xx 分钟前」。
- **减少动效**（系统设置 `prefers-reduced-motion`）：不画彗星，用静态渐变代替；不放烟花。

## 9. 手机端
- 地球全屏，Manifest 改成可拖动的底部抽屉（收起 / 半开 / 全开三档）。
- 详情页替换抽屉的内容，不另开页面。
- 添加入口：右下角悬浮按钮；同时支持 iOS 分享菜单（PWA share target，v0.2）。
- 性能：手机上像素比上限 1.5，FPS 掉下来时先关 bloom。
